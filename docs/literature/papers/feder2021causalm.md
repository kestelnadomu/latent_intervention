# CausaLM: Causal Model Explanation Through Counterfactual Language Models

Amir Feder; Nadav Oved; Uri Shalit; Roi Reichart. 2021. Computational Linguistics 47(2).

- [Primary source](https://aclanthology.org/2021.cl-2.13/)

## Project relevance (triage)

Text-counterfactual representation precedent for estimating a concept's causal effect on model behavior. It fine-tunes a contextual encoder with auxiliary adversarial tasks, unlike our post-hoc editing of a frozen encoder.
