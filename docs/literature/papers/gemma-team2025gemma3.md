# Gemma 3 Technical Report

Gemma Team, Google DeepMind. 2025. Technical report / arXiv preprint.

- [Primary source](https://storage.googleapis.com/deepmind-media/gemma/Gemma3Report.pdf)

## Project relevance (triage)

Architecture and scaling background for the project's comparison of Gemma 3 decoder capacities in CV reconstruction.

## Notes and caveats

The March 2025 report describes the original 1B–27B Gemma 3 family. It does not by itself document the later 270M release or establish that a larger decoder can recover facts absent from an embedding.
