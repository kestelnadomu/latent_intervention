# Exogenous Isomorphism for Counterfactual Identifiability

Yikang Chen; Dehui Du. 2025. ICML, PMLR 267, pp. 8022–8064.

- [Proceedings](https://proceedings.mlr.press/v267/chen25p.html)
- [Preprint](https://arxiv.org/abs/2505.02212)

## Project relevance (triage)

Directly relevant to the meaning of shared exogenous coordinates: develops exogenous-isomorphism conditions for counterfactual identification, including sufficient conditions for restricted SCM families.

## Notes and caveats

A generic state-conditioned neural flow does not inherit these conditions merely because it is invertible. Read the exact structural restrictions before making an identification claim for our shared-noise transport.
