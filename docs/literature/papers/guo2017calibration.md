# On Calibration of Modern Neural Networks

Chuan Guo; Geoff Pleiss; Yu Sun; Kilian Q. Weinberger. 2017. ICML, PMLR 70, pp. 1321–1330.

- [Proceedings](https://proceedings.mlr.press/v70/guo17a.html)

## Project relevance (triage)

Standard reference for confidence calibration and temperature scaling. Supports distinguishing semantic-reader accuracy from trustworthy probabilities when those probabilities weight symbolic target mixtures.

## Notes and caveats

Our project currently measures calibration descriptively; this citation does not imply that temperature scaling is implemented or that marginal calibration establishes joint or post-intervention calibration.
