# COFFEE: Counterfactual Fairness for Personalized Text Generation in Explainable Recommendation

Nan Wang; Qifan Wang; Yi-Chia Wang; Maziar Sanjabi; Jingzhou Liu; Hamed Firooz; Hongning Wang; Shaoliang Nie. 2023. EMNLP, pp. 13258–13275.

- [Proceedings](https://aclanthology.org/2023.emnlp-main.819/)

## Project relevance (triage)

Connects counterfactual fairness to personalized explanation generation. Relevant when motivating fairness-oriented text generation rather than only representation-level debiasing.

## Notes and caveats

Recommendation explanations, their fairness target and model training differ from our post-hoc document-embedding intervention. A comparison must specify which fairness definition and information-preservation criterion are shared.
