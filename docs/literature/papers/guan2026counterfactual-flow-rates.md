# Counterfactual Generation via Flow Matching: Coupling-Sensitive End-to-End Rates

Yunrui Guan; Krishnakumar Balasubramanian; Shiva Prasad Kasiviswanathan. 2026. arXiv preprint, first posted 2026-10-01; v1 screened.

- [Preprint](https://arxiv.org/abs/2610.01193)
- [Paper (version screened)](https://arxiv.org/html/2610.01193v1)

## Project relevance (triage)

Studies distributional error for counterfactual generation with flow matching, with bounds sensitive to the endpoint coupling. Relevant to explaining what coupling choices can affect beyond endpoint density fit.

## Notes and caveats

The stated analysis involves smoothing, a corrected stochastic sampler, overlap, bounded/clipped outcomes and nuisance-model accuracy. It is not an off-the-shelf guarantee for our deterministic flow or the true individual-level coupling.
