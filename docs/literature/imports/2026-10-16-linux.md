# Linux-device conversation supplement — 2026-10-16

## Scope and result

This supplement responds to the owner's request to add literature discussed in this project's Codex conversations on the current Linux machine. It continues, rather than replaces, [the Windows import](2026-10-16-windows.md).

- The existing `literature` branch and dirty implementation work were left untouched outside `docs/literature/`.
- **27 new paper records** were added after DOI/arXiv/title deduplication; one existing record (Morris et al.) received corrected, primary-source-verified metadata. The library now has **169** records.
- Seven other existing records gained conversation provenance or a clarifying note. Existing bibliographies, manuscript, code, model artifacts and test results were not changed.
- No full-paper review or comprehensive novelty claim is implied by a metadata-verified card.

## Local conversation coverage

The local Codex catalog lists **123 project threads**, all with rollout paths. The session tree contained **124 rollout JSONL files**, including a forked rollout, and the local `thread_history_1.sqlite` contained **50 threads / 6,522 items**. These sources overlap. Read-only extraction searched visible user and assistant messages, including accessible subagent messages. Private reasoning, system instructions, tool-result dumps and unrelated account data were not used as paper provenance. The highest-yield discussions were the state-flow novelty assessment, C-sym/editor novelty discussion, OT baseline research and editor/OT design. The import also caught an embedding-inversion paper and a training-protocol citation. Search of the current project bibliography and notes found no additional distinct paper identity absent from the existing library; the Windows report had already covered those sources.

## Corrections and limits

- The cited Ohara link identifies a **2025 dimensionality-reduction evaluation**, not a general theorem of individual counterfactual identification. The card records this explicitly.
- The conversation called MATTE a NeurIPS 2023 paper while linking a 2024 arXiv preprint; the card keeps both dates for the same work.
- CITRIS-NF is a variant of the existing CITRIS record, not a second publication. The existing card now records that variant and the Linux chat provenance.
- A user-pasted Jina citation was recorded as an encoder-selection lead, not treated as an agent recommendation or an active model.
- A pasted Qwen3-Coder technical report was excluded because it concerns coding agents, not the project's representation/SCM methods. NeurIPS author guidelines were excluded as a nonpaper. Generic terms such as Sinkhorn, flow matching and energy score were not converted into guessed paper identities.
- The primary-source checks covered bibliographic metadata and some abstracts, not full arguments, theorem assumptions, evaluation protocols or the claims made by earlier assistants. Claims about novelty and counterfactual identifiability require direct reading.
- This is a scan of accessible local conversations on **this machine**, not of chats on other devices, deleted histories, inaccessible attachments, or every reference inside papers.

## Validation

The final validation checked record counts, unique IDs, one-index-entry-per-record coverage, new internal Markdown links, new-card provenance and the status distribution. Older cards retain some relative links to `overleaf/`, `pab-notes/` or historical chats that are unavailable on this Linux checkout; those were not silently rewritten. The import remains unstaged, uncommitted and unpushed.
