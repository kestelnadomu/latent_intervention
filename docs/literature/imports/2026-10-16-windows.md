## Verification and limitations

Primary sources were used selectively to verify central/newly resolved identities and suspicious citations. Important corrections are collected in [unresolved.md](../unresolved.md); the GAN-fairness, Joo and RegDiff attributions were corrected only in the new library. Version differences were retained for later bibliography cleanup.

No paper is marked fully reviewed merely because an abstract or metadata page was inspected. Older assistant prose may conflate prediction fairness, representation invariance, semantic consistency and identification; it is retained only as discovery context, not copied as established scientific conclusions.

This import covers recoverable material on this device, not other devices, deleted chats, all attachments, unprojected tool citations, all branches of Git history or every reference cited inside another paper. A subsequent agent should append new provenance and fill gaps rather than replace the collection.
